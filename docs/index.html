Connect Clients on Your Local Network

Copy-paste ready snippets for mobile apps, terminal, and scripts on the same Wi-Fi.

Python (OpenAI SDK) 

from openai import OpenAI

client = OpenAI(
    base_url="http://192.168.1.100:8080/v1",  # Replace with laptop LAN IP
    api_key="sk-local-noora-default-lan-key"
)

response = client.chat.completions.create(
    model="local-ai",
    messages=[{"role": "user", "content": "Hello Noora!"}]
)

print(response.choices[0].message.content)
